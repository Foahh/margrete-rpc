## 这是什么

如果你想制作复杂的变速效果，不妨利用这些工具函数。
这些变速工具会返回变速事件（[`TimelineSpeedEvent`](/docs/reference/chart/events/TimelineSpeedEvent)）列表。

```python
from margrete_rpc.chart.util import timing_easing

with m.open_edit() as tx:
    tx.chart.tils.extend(
        timing_easing(
            t0=(0, 0),
            t1=(1, 0),
            start_speed=0.0,
            end_speed=10.0,
            count=8,
            easing="in_out_cubic",
        )
    )
```

## 抖动

使用 [`timing_glitch(...)`](/docs/reference/chart/util/timing) 可以制作抖动效果。它会在 `t0` 到 `t1` 之间均匀分布 `count` 次速度尖峰，不包含 `t1`。

每个尖峰持续 `spike_ticks` tick（默认为 5），随后速度重置为 `base_speed`。

```python
from margrete_rpc.chart.util import timing_glitch

events = timing_glitch(
    t0=(24, 0),
    t1=(24, 2),
    count=4,
    speed_range=2.0,
    base_speed=1.0,
    spike_ticks=5
)

with m.open_edit() as tx:
    tx.chart.tils.extend(events)
```

尖峰速度以 `base_speed` 为基准，向两侧交替出现：

```python
# base_speed=1.0, speed_range=2.0
# 抖动速度: -1.0, 3.0, -1.0, 3.0
```

```python
freeze = timing_glitch(
    t0=(32, 0),
    t1=(33, 0),
    count=8,
    speed_range=3.0,
    base_speed=0.0,
)
```

`timing_glitch(...)` 会为每个尖峰返回两个事件：尖峰事件，以及 `spike_ticks` 个 tick 之后的重置事件。因此 `count` 为 `8` 时会返回 `16` 个事件。

## 速度渐变

如果你希望速度从 `start_speed` 缓动到 `end_speed`，可以使用 [`timing_easing(...)`](/docs/reference/chart/util/timing)。

```python
from margrete_rpc.chart.util import timing_easing

slow_into_fast = timing_easing(
    t0=(40, 0),
    t1=(44, 0),
    start_speed=0.5,
    end_speed=2.0,
    count=16,
    easing="in_out_sine",
)

with m.open_edit() as tx:
    tx.chart.tils.extend(slow_into_fast)
```

`count` 表示 `t0` 和 `t1` 之间的细分数量。这个函数会返回 `count + 1` 个事件，包括一个精确位于 `t0` 的事件和一个精确位于 `t1` 的事件。

## 位移可控的速度渐变

如果你需要固定变速区间内的总位移，请使用 [`timing_easing_by_disp(...)`](/docs/reference/chart/util/timing)。

```python
from margrete_rpc.chart.util import timing_easing_by_disp

motion = timing_easing_by_disp(
    t0=(48, 0),
    t1=(52, 0),
    base_speed=1.0,
    count=24,
    easing="out_cubic",
)

with m.open_edit() as tx:
    tx.chart.tils.extend(motion)
```
