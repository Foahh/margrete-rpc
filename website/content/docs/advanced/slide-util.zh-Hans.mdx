## Crease

[`crease(...)`](/docs/reference/chart/util/crease) 会围绕一条 base curve 创建锯齿形轨迹。首尾 points 保持在 base 上，中间 points 在正负 offset 之间交替。

```python
from margrete_rpc.chart.util import Curve, crease

base = Curve(t=(0, 0), x=2, h=70).to(t=(1, 0), x=12, h=120, ease_x="out_quad")

slide = crease(base, count=6, x_range=2).to_slide(w=4).clamp()
air = crease(base, count=6, x_range=0, h_range=20).to_air_slide(w=4)
```

如果 offset 可能把 note 推出 lane field，请在 materialize 之后使用 `.clamp()`。

## Envelope

[`envelope(...)`](/docs/reference/chart/util/envelope) 会在两条边界 curves 之间来回穿梭。两条 curves 必须拥有相同的开始和结束时间。`count` 为偶数时会回到 `inner` 结束；为奇数时会在 `outer` 结束。

```python
from margrete_rpc.chart.util import Curve, envelope

inner = Curve(t=(0, 0), x=2).to(t=(1, 0), x=6, ease_x="in_sine")
outer = Curve(t=(0, 0), x=10).to(t=(1, 0), x=14, ease_x="out_sine")

slide = envelope(inner, outer, count=4).to_slide(w=2)
```

## Rain

[`rain(...)`](/docs/reference/chart/util/rain) 会在一个时间范围内生成一组短的 `AirCrush` notes。如果希望脚本每次运行都得到相同的散布结果，请使用 `seed=`。

```python
from margrete_rpc.chart.util import rain

drops = rain(
    t0=(0, 0),
    t1=(4, 0),
    step=(1, 16),
    length=(1, 16),
    x_range=(0, 15),
    h_range=(60, 140),
    w=1,
    color="sky",
    seed=42,
)

tx.chart.notes.extend(drops)
```

`x_range` 和 `h_range` 都是闭区间。原本会超出 `t1` 的 drops 会被截断，使其正好在 `t1` 结束。
