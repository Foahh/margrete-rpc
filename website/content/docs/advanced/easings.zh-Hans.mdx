title: Easings
---

Easing 描述一个值如何在一段时间内从 `0` 移动到 `1`。

```python
from margrete_rpc.chart.util import Curve, timing_easing

slide = Curve(t=(0, 0), x=0).to(t=(1, 0), x=12, ease_x="in_out_sine").to_slide(w=4)

speed_events = timing_easing(
    t0=(4, 0),
    t1=(8, 0),
    start_speed=0.5,
    end_speed=2.0,
    count=16,
    easing="out_cubic",
)
```

## 该使用哪个名称

每个 easing family 都有三个方向：

| 方向       | 含义                               |
| ---------- | ---------------------------------- |
| `in_*`     | 开始较慢，越接近结尾变化越明显。   |
| `out_*`    | 一开始变化较快，越接近结尾越慢。   |
| `in_out_*` | 开始较慢，中段变快，然后再次放慢。 |

常见选择：

| 名称          | 适合用途                          |
| ------------- | --------------------------------- |
| `linear`      | 匀速移动，或等间隔的速度变化。    |
| `in_quad`     | 向目标简单加速。                  |
| `out_quad`    | 向目标简单减速。                  |
| `in_out_sine` | 两点之间平滑、自然的移动。        |
| `out_cubic`   | 比 `out_quad` 更明显的 ease-out。 |
| `in_out_expo` | 戏剧性的慢-快-慢移动。            |

## 内置名称

| Family | 名称                                    |
| ------ | --------------------------------------- |
| Linear | `linear`                                |
| Sine   | `in_sine`, `out_sine`, `in_out_sine`    |
| Quad   | `in_quad`, `out_quad`, `in_out_quad`    |
| Cubic  | `in_cubic`, `out_cubic`, `in_out_cubic` |
| Quart  | `in_quart`, `out_quart`, `in_out_quart` |
| Quint  | `in_quint`, `out_quint`, `in_out_quint` |
| Expo   | `in_expo`, `out_expo`, `in_out_expo`    |
| Circ   | `in_circ`, `out_circ`, `in_out_circ`    |

## 自定义 easings

任何接受 easing 名称的位置，也可以传入 [`Easing`](/docs/reference/chart/util/easing/Easing) 对象，或一个从 `0..1` 映射到 `0..1` 的 callable。

```python
import math
from margrete_rpc.chart.util import Curve

def stepped_4(t: float) -> float:
    return math.floor(t * 4) / 4 if t < 1 else 1.0

slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(1, 0), x=12, ease_x=stepped_4)
    .to_slide(w=4)
)
```

自定义 easing 通常应该在输入 `0` 时返回 `0`，在输入 `1` 时返回 `1`。这样生成的 curves 和 speed ramps 才能准确落在起点值与终点值上。
