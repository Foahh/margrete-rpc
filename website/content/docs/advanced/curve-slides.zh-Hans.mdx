title: Curve Slides
description: 勾勒 curved slides、air slides 和 air-crush paths。
---

[`Curve`](/docs/reference/chart/util/curve/Curve) 工具可以帮助你先勾勒出与宽度无关的 slide paths，再把它们转换成 notes。常见流程是先把路径画成 curve，然后 materialize 为 [`Slide`](/docs/reference/chart/notes/long/Slide)、[`AirSlide`](/docs/reference/chart/notes/air/AirSlide) 或 [`AirCrush`](/docs/reference/chart/notes/long/AirCrush)。如果要手写 notes 和 joints，请从 [Notes](/docs/basic/notes#long-notes) 开始。

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.util import Curve

with Margrete() as m:
    with m.open_edit() as tx:
        slide = (
            Curve(t=(0, 0), x=0)
            .to(t=(1, 0), x=12, ease_x="in_out_sine")
            .to_slide(w=4)
            .clamp()
        )

        tx.chart.notes.append(slide)
```

## 心智模型

[`Curve`](/docs/reference/chart/util/curve/Curve) 会存储 [`Waypoint`](/docs/reference/chart/util/curve/Waypoint) 值，包含：

| 字段     | 含义                                                 |
| -------- | ---------------------------------------------------- |
| `t`      | Tick 或 `Position` tuple。                           |
| `x`      | Lane position。                                      |
| `h`      | Air height。                                         |
| `ease_x` | 进入这个 waypoint 时 lane movement 使用的 easing。   |
| `ease_h` | 进入这个 waypoint 时 height movement 使用的 easing。 |

第一个 waypoint 用于锚定 curve，因此它的 easing values 不会影响路径。Materialize 为 ground slide 时会保留 `h`，但它只有在 air-slide 和 air-crush paths 上才有可见效果。

使用 [`to(...)`](/docs/reference/chart/util/curve/Curve#functions) 添加 leg。每个目标时间都必须晚于当前 curve 末尾。

```python
from margrete_rpc.chart.util import Curve

path = (
    Curve(t=(0, 0), x=2, h=60)
    .to(t=(0, 2), x=12, h=120, ease_x="out_cubic", ease_h="in_sine")
    .to(t=(1, 0), x=4, h=80, ease_x="in_cubic", ease_h="out_sine")
)
```

Positions 的解析方式与 note constructors 相同。在 `with m.open_edit()` 代码块内，tuple positions 会使用谱面的 time signatures。完整 timing model 见 [Time & Position](/docs/basic/time-position)。

## Materialize notes

Ground slides 使用 [`to_slide()`](/docs/reference/chart/util/curve/Curve#functions)。`w` 值会应用到每个生成的 joint。

```python
from margrete_rpc.chart.util import Curve

slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(0, 2), x=8, ease_x="out_quad")
    .to(t=(1, 0), x=4, ease_x="in_quad")
    .to_slide(w=4)
)
```

如果生成的路径应该位于 air lane，请使用 [`to_air_slide()`](/docs/reference/chart/util/curve/Curve#functions)。在 curve 起点和需要改变高度的 legs 上传入 `h=`。

```python
from margrete_rpc.chart.notes import Tap
from margrete_rpc.chart.util import Curve

air_slide = (
    Curve(t=(0, 0), x=4, h=60)
    .to(t=(0, 2), x=10, h=120, ease_x="in_out_sine", ease_h="out_quad")
    .to(t=(1, 0), x=6, h=80, ease_x="in_out_sine", ease_h="in_quad")
    .to_air_slide(w=4)
)

parent = Tap(t=air_slide.t, x=air_slide.x, w=air_slide.w).add_air(air_slide)
```

Air-crush traces 使用 [`to_air_crush()`](/docs/reference/chart/util/curve/Curve#functions)。`gap` 可以是 raw ticks，也可以是 `(1, 16)` 这样的 division tuple。

```python
from margrete_rpc.chart.util import Curve

crush = (
    Curve(t=(0, 0), x=2, h=80)
    .to(t=(1, 0), x=14, h=120, ease_x="out_expo", ease_h="in_out_sine")
    .to_air_crush(w=2, gap=(1, 16), color="blue")
)
```

`Curve` 会把 eased legs 采样成整数 waypoints。Linear legs 会保持紧凑，而 curved legs 会得到足够的 control points，以便转换为 notes 后重现勾勒出的运动。

`ease_x` 和 `ease_h` 接受内置 easing 名称、[`Easing`](/docs/reference/chart/util/easing/Easing) 对象，或自定义 callables。完整列表和自定义 easing 规则见 [Easings](/docs/advanced/easings)。

## 检查和组合

调用 [`points()`](/docs/reference/chart/util/curve/Curve#functions) 可以在创建 note 之前预览量化后的路径。

```python
path = Curve(t=(0, 0), x=0).to(t=(1, 0), x=12, ease_x="in_out_sine")

for point in path.points():
    print(point.t, point.x, point.h)
```

使用 [`at(tick)`](/docs/reference/chart/util/curve/Curve#functions) 在指定 tick 上求 curve 的值。这对于构建跟随或穿过另一条路径的派生路径很有用。

```python
path = Curve(t=0, x=0, h=80).to(t=960, x=12, h=120)
mid = path.at(480)

print(mid.x, mid.h)
```

使用 [`then()`](/docs/reference/chart/util/curve/Curve#functions) 或 `+` 连接 curves。如果第二条 curve 从第一条 curve 的结束 tick 开始，共享 point 会被去重。

```python
from margrete_rpc.chart.util import Curve

out = Curve(t=(0, 0), x=0).to(t=(0, 2), x=12, ease_x="out_cubic")
back = Curve(t=(0, 2), x=12).to(t=(1, 0), x=4, ease_x="in_cubic")

slide = (out + back).to_slide(w=4)
```

如果想把已有 long note 作为 curve 读入，进行组合后再 materialize，可以使用 [`Curve.from_note()`](/docs/reference/chart/util/curve/Curve#functions)。

```python
from margrete_rpc.chart.util import Curve

path = Curve.from_note(existing_slide)

for point in path.waypoints[1:]:
    point.ease_x = "out_cubic"

copy = path.to_slide(w=existing_slide.w)
```

宽度会被有意丢弃，因为 `Curve` 本身与宽度无关。
