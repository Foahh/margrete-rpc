---
title: Timing Utilities
description: 生成常见的 scroll-speed patterns。
---

Timing utilities 会生成 [`TimelineSpeedEvent`](/docs/reference/chart/events/TimelineSpeedEvent) 列表。把这些 events 追加到 `tx.chart.events.til`，即可随时间改变 scroll speed。

当你希望得到可复现的 timing effects，而不是手写每一个 speed event 时，可以使用这些 helpers。

```python
from margrete_rpc.chart.util import timing_easing

with m.open_edit() as tx:
    tx.chart.events.til.extend(
        timing_easing(
            t0=(16, 0),
            t1=(20, 0),
            start_speed=1.0,
            end_speed=2.0,
            count=8,
            easing="linear",
        )
    )
```

## Glitch stutters

使用 [`timing_glitch(...)`](/docs/reference/chart/util/timing#functions) 可以快速制作 stutter 效果。它会从 `t0` 到 `t1` 之前均匀放置 `count` 个 speed spikes。每个 spike 持续一个 tick，然后 speed 重置为 `base_speed`。

```python
from margrete_rpc.chart.util import timing_glitch

events = timing_glitch(
    t0=(24, 0),
    t1=(24, 2),
    count=4,
    speed_range=2.0,
    base_speed=1.0,
)

with m.open_edit() as tx:
    tx.chart.events.til.extend(events)
```

Spike speeds 会围绕 `base_speed` 交替：

```python
# base_speed=1.0, speed_range=2.0
# spike speeds: -1.0, 3.0, -1.0, 3.0
```

如果希望谱面围绕正常 scroll speed 抖动，请使用 `base_speed=1.0`。如果希望得到短暂前后跳动的 freeze-style stutter，请使用 `base_speed=0.0`。

```python
freeze = timing_glitch(
    t0=(32, 0),
    t1=(33, 0),
    count=8,
    speed_range=3.0,
    base_speed=0.0,
)
```

`timing_glitch(...)` 每个 spike 返回两个 events：spike event，以及一 tick 之后的 reset event。`count` 为 `8` 时会返回 `16` 个 events。

## Speed ramps

当你希望 speed 本身从 `start_speed` 移动到 `end_speed` 时，使用 [`timing_easing(...)`](/docs/reference/chart/util/timing#functions)。

```python
from margrete_rpc.chart.util import timing_easing

slow_into_fast = timing_easing(
    t0=(40, 0),
    t1=(44, 0),
    start_speed=0.5,
    end_speed=2.0,
    count=16,
    easing="in_out_sine",
)

with m.open_edit() as tx:
    tx.chart.events.til.extend(slow_into_fast)
```

Easing 控制 speed 值如何变化：

| Easing        | 结果                                          |
| ------------- | --------------------------------------------- |
| `linear`      | 整个范围内 speed 等幅变化。                   |
| `in_quad`     | 一开始 speed 变化较小，接近 `t1` 时变化较大。 |
| `out_quad`    | 一开始 speed 变化较大，接近 `t1` 时变化较小。 |
| `in_out_sine` | 平滑开始，平滑结束。                          |

内置名称完整列表和自定义 easing 规则见 [Easings](/docs/advanced/easings)。

`count` 是 `t0` 和 `t1` 之间的细分数量。helper 会返回 `count + 1` 个 events，包括一个精确位于 `t0` 的 event 和一个精确位于 `t1` 的 event。

## Displacement-shaped timing

如果你关心的是滚动运动的形状，而不只是列出的 speed values，请使用 [`timing_easing_by_disp(...)`](/docs/reference/chart/util/timing#functions)。

这个 helper 会采样 easing curve 的斜率。曲线陡峭的部分会变成高 speed，平坦的部分会变成低 speed。累计 scroll displacement 会遵循 easing 的形状。

```python
from margrete_rpc.chart.util import timing_easing_by_disp

motion = timing_easing_by_disp(
    t0=(48, 0),
    t1=(52, 0),
    base_speed=1.0,
    count=24,
    easing="out_cubic",
)

with m.open_edit() as tx:
    tx.chart.events.til.extend(motion)
```

两个 easing helpers 的区别很重要：

| Helper                  | 采样对象        | 可以理解为                           |
| ----------------------- | --------------- | ------------------------------------ |
| `timing_easing`         | Easing value    | “把 speed 设为这个 eased value。”    |
| `timing_easing_by_disp` | Easing velocity | “用这个 ease 移动 scroll position。” |

当 `easing="linear"` 时，`timing_easing_by_disp(...)` 会产生恒定 speed，因为线性曲线的斜率恒定。当 `easing="in_quad"` 时，speed 会加速，因为曲线越接近结尾越陡。
