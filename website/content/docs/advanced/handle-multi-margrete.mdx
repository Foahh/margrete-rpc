---
title: Connect Multiple Margrete
---

With no arguments, `Margrete()` auto-detects the running plugin from named pipes named `margrete-XXXX`. This is the normal form when one Margrete window is open. If you have multiple running instances, pass the four-digit code shown in the plugin dialog:

```python
from margrete_rpc import Margrete, list_instances

# list all running instances
for inst in list_instances():
    print(inst.instance_id, inst.pipe_name)

# connect by four-digit code (left Margrete)
with Margrete("0421") as m_left:
    print(m_left.status())

# the full pipe name also works (right Margrete)
with Margrete("margrete-0999") as m_right:
    print(m_right.status())
```
