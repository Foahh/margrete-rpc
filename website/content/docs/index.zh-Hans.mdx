**Margrete RPC** 是 [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro) 的插件。它可以让你通过 Python 脚本直接编辑谱面。

## 1. 环境要求

- Python 3.13 或更高版本
- Margrete 1.8.0 或更高版本

## 2. 安装 Python 模块

{/* prettier-ignore */}
<Tabs items={["pip", "uv"]}>
  <Tab value="pip">
    ```bash
    pip install margrete-rpc
    ```
  </Tab>
  <Tab value="uv">
    ```bash
    uv add margrete-rpc
    ```
  </Tab>
</Tabs>

## 3. 安装 Margrete 插件

1. 从 [GitHub Releases](https://github.com/Foahh/margrete-rpc/releases) 下载最新版本。

2. 打开 `margrete-rpc-vX.X.X.zip`，将 `margrete-rpc.dll` 和 `margrete-rpc.ini` 复制到 Margrete 的 `plugins` 目录。

   <Files>
     <Folder name="Margrete" defaultOpen disabled>
       <Folder name="data" disabled />
       <Folder name="i18n" disabled />
       <Folder name={<span className="font-medium">plugins 👈</span>} defaultOpen disabled>
         <File name={<span className="font-medium">margrete-rpc.dll</span>} />
         <File name={<span className="font-medium">margrete-rpc.ini</span>} />
       </Folder>
       <Folder name="scripts" disabled />
       <File
         name="Margrete.exe"
         icon={<img src={MargreteIcon} alt="Margrete icon" width="16" height="16" />}
       />
     </Folder>
   </Files>

3. 重启 Margrete。然后打开 **Extensions** → **Manage Extensions**，勾选 **margrete-rpc.dll**，再点击 **Confirm**。

   <ImageZoom src={EnableThePluginImage} alt="Enable the plugin" width="500" />

4. 当菜单中出现 **Extensions** → **Margrete RPC** 时，说明安装已经完成。

   <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
