**Margrete RPC** 是 [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro) 的插件。它可以让你通过 Python 脚本直接编辑谱面。

## 前置需求

{/* prettier-ignore */}
<Callout title="环境要求" type="info">
  - Python 3.13 或更高版本 
  - Margrete 1.8.0 或更高版本
</Callout>


### 1. 安装 Python 模块

{/* prettier-ignore */}
<Tabs items={["pip", "uv"]}>
  <Tab value="pip">
    ```bash
    pip install margrete-rpc
    ```
  </Tab>
  <Tab value="uv">
    ```bash
    uv add margrete-rpc
    ```
  </Tab>
</Tabs>

### 2. 安装 Margrete 插件

1. 从 [GitHub Releases](https://github.com/Foahh/margrete-rpc/releases) 下载最新版本。

2. 打开 `margrete-rpc-vX.X.X.zip`，将 `margrete-rpc.dll` 和 `margrete-rpc.ini` 复制到 Margrete 的 `plugins` 目录。

       <Folder name={<span className="font-medium">plugins 👈</span>} defaultOpen disabled>
         <File name={<span className="font-medium">margrete-rpc.dll</span>} />

       </Folder>

       <File
         name="Margrete.exe"
         icon={<img src={MargreteIcon} alt="Margrete icon" width="16" height="16" />}
       />
     </Folder>
   </Files>

3. 重启 Margrete。然后打开 **Extensions** → **Manage Extensions**，勾选 **margrete-rpc.dll**，再点击 **Confirm**。

## 快速上手

1. 在 Margrete 中打开 **Extensions** → **Margrete RPC** 启动插件。

   <div className="flex items-center justify-start gap-1">
     <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
     <div className="flex items-center">👉</div>
     <ImageZoom src={ActivateThePluginImage} alt="Start the plugin" width="400" />
   </div>

   <Callout type="info">每次开启 Margrete 后，都需要重新启动插件。</Callout>

2. 创建一个名为 `example.py` 的文件：

   ```python
   from margrete_rpc import Margrete
   from margrete_rpc.chart.notes import Tap

   with Margrete() as m:  # 会自动检测正在运行的插件
       status = m.status()
       print(f"Plugin v{status.server_version} (pid {status.pid})")
       print(f"Log: {status.log_path}")

       with m.open_edit() as tx:
           tx.chart.notes.append(Tap(t=0, x=0, w=4))
           # 当这个代码块正常退出时，修改才会被应用
   ```

3. 运行脚本并查看编辑器：

   ```bash
   python example.py
   ```

这段代码会连接到 Margrete 插件，打印服务器状态，并向谱面中追加一个 Tap 物件。
