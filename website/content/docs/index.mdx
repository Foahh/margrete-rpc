**Margrete RPC** is a Margrete plugin plus a [Python client package](/docs/reference/client) that lets you script chart editing for [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro).

Use it to read and rewrite charts programmatically: place notes, edit events, and apply changes inside the editor.

## Requirements

- Python 3.13 or later
- Margrete 1.8.0 or later

## Installation

### 1. Install the plugin

1. Download the latest release from the [GitHub Releases page](https://github.com/Foahh/margrete-rpc/releases).

2. Open `margrete-rpc-vX.X.X.zip` and copy `margrete-rpc.dll` and `margrete-rpc.ini` to your Margrete plugins directory.

3. Restart Margrete. Then open **Extensions** → **Manage Extensions**, enable **margrete-rpc.dll**, and click **Confirm**.

   <ImageZoom src={EnableThePluginImage} alt="Enable the plugin" width="500" />

The included `margrete-rpc.ini` starts both local transports by default:

```ini
[server]
transport = both
host = 127.0.0.1
port = auto
pipe_name = auto
```

`transport = both` publishes a TCP endpoint and a Windows named-pipe endpoint. Use `transport = tcp` or `transport = pipe` if you want to expose only one transport.

## Quick start

1. In Margrete, open **Extensions** → **Margrete RPC** to start the plugin.

   <div className="flex items-center justify-start gap-1">
     <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
     <div className="flex items-center">👉</div>
     <ImageZoom src={ActivateThePluginImage} alt="Start the plugin" width="400" />
   </div>

   <Callout type="info">You need to start the plugin each time Margrete restarts.</Callout>

2. Create a file called `example.py`:

   ```python
   from margrete_rpc import Margrete
   from margrete_rpc.chart.notes import Tap

   with Margrete() as m:  # auto-detect the running plugin instance and transport
       status = m.status()
       print(f"Plugin v{status.server_version} (pid {status.pid})")
       print(f"Log: {status.log_path}")

       with m.open_edit() as tx:
           tx.chart.notes.append(Tap(t=0, x=0, w=4))
           # changes are applied when this block exits successfully
   ```

   This connects to Margrete, prints the [`ServerStatus`](/docs/reference/client/ServerStatus), opens an [edit transaction](/docs/basic/edit-transactions), and appends a [`Tap`](/docs/reference/chart/notes/ground/Tap) note to the chart.

3. Run the script and check the editor:

   ```bash
   python example.py
   ```

   A new tap note will appear in the editor.
