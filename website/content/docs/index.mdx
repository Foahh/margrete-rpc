**Margrete RPC** is a [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro) plugin that lets you script chart editing via Python.

## Prerequisites

{/* prettier-ignore */}
<Callout title="Requirements" type="info">
  - Python 3.13 or later 
  - Margrete 1.8.0 or later
</Callout>


### 1. Install the Python module

{/* prettier-ignore */}
<Tabs items={["pip", "uv"]}>
  <Tab value="pip">
    ```bash
    pip install margrete-rpc
    ```
  </Tab>
  <Tab value="uv">
    ```bash
    uv add margrete-rpc
    ```
  </Tab>
</Tabs>

### 2. Install the Margrete plugin

1. Download the latest release from the [GitHub Releases](https://github.com/Foahh/margrete-rpc/releases).

2. Open `margrete-rpc-vX.X.X.zip` and copy `margrete-rpc.dll` and `margrete-rpc.ini` to your Margrete `plugins` directory.

   <Files>
     <Folder name="Margrete" defaultOpen disabled>

         <File name={<span className="font-medium">margrete-rpc.dll</span>} />
         <File name={<span className="font-medium">margrete-rpc.ini</span>} />

       />
     </Folder>
   </Files>

3. Restart Margrete. Then open **Extensions** → **Manage Extensions**, tick **margrete-rpc.dll**, and click **Confirm**.

## Quick start

1. In Margrete, open **Extensions** → **Margrete RPC** to start the plugin.

   <div className="flex items-center justify-start gap-1">
     <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
     <div className="flex items-center">👉</div>
     <ImageZoom src={ActivateThePluginImage} alt="Start the plugin" width="400" />
   </div>

   <Callout type="info">You need to start the plugin each time Margrete restarts.</Callout>

2. Create a file called `example.py`:

   ```python
   from margrete_rpc import Margrete
   from margrete_rpc.chart.notes import Tap

   with Margrete() as m:  # auto-detect the running plugin instance and transport
       status = m.status()
       print(f"Plugin v{status.server_version} (pid {status.pid})")
       print(f"Log: {status.log_path}")

       with m.open_edit() as tx:
           tx.chart.notes.append(Tap(t=0, x=0, w=4))
           # changes are applied when this block exits successfully
   ```

3. Run the script and check the editor:

   ```bash
   python example.py
   ```

   This connects to Margrete, prints the plugin status, and appends a Tap note to the chart.
