**Margrete RPC** is a [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro) plugin that lets you script chart editing via Python.

## 1. Requirements

- Python 3.13 or later
- Margrete 1.8.0 or later

## 2. Install the Python module

{/* prettier-ignore */}
<Tabs items={["pip", "uv"]}>
  <Tab value="pip">
    ```bash
    pip install margrete-rpc
    ```
  </Tab>
  <Tab value="uv">
    ```bash
    uv add margrete-rpc
    ```
  </Tab>
</Tabs>

## 3. Install the Margrete plugin

1. Download the latest release from the [GitHub Releases](https://github.com/Foahh/margrete-rpc/releases).

2. Open `margrete_rpc-vX.X.X-windows-x64.zip` and copy `margrete_rpc.dll` and `margrete_rpc.ini` to your Margrete `plugins` directory.

   <Files>
     <Folder name="Margrete" defaultOpen disabled>
       <Folder name="data" disabled />
       <Folder name="i18n" disabled />
       <Folder name={<span className="font-medium">plugins 👈</span>} defaultOpen disabled>
         <File name={<span className="font-medium">margrete_rpc.dll</span>} />
         <File name={<span className="font-medium">margrete_rpc.ini</span>} />
       </Folder>
       <Folder name="scripts" disabled />
       <File
         name="Margrete.exe"
         icon={<img src={MargreteIcon} alt="Margrete icon" width="16" height="16" />}
       />
     </Folder>
   </Files>

3. Restart Margrete. Then open **Extensions** → **Manage Extensions**, tick **margrete_rpc.dll**, and click **Confirm**.

   <ImageZoom src={EnableThePluginImage} alt="Enable the plugin" width="500" />

4. The installation is complete when **Extensions** → **Margrete RPC** appears in the menu.

   <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
