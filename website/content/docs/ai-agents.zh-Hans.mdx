任何能编写代码的 AI 助手（如 Claude Code、Codex、Cursor 等）都可以直接驱动 Margrete RPC。本页介绍如何为助手提供足够的上下文，以获得更准确的代码建议。

## 提供 API 上下文

### 方式一：使用源码

将 `margrete_rpc` 的源码交给助手，能获得最准确的 API 信息。

<Tabs items={["已安装的包", "克隆仓库"]}>
  <Tab value="已安装的包">
    让编码助手运行以下命令获取包路径，读取已安装的源码：

    ```bash
    python -c "import margrete_rpc, os; print(os.path.dirname(margrete_rpc.__file__))"
    ```

  </Tab>
  <Tab value="克隆仓库">
    ```bash
    git clone https://github.com/Foahh/margrete-rpc
    ```

    将 `python/margrete_rpc/` 目录添加到助手的上下文中。

  </Tab>
</Tabs>

### 方式二：使用文档

本站每个页面都提供 Markdown 版本，更适合用来在网页上向 AI 提问：

- **全站索引** —— [`/llms.txt`](https://mg.foahh.com/llms.txt) 列出了所有页面及其链接，适合作为起点。
- **单个页面** —— 点击页面顶部的 **Copy Markdown** 或 **Open** 按钮，或在页面 URL 后追加 `.md`。
- **API 参考** —— [margrete_rpc](/docs/reference) 中列出了所有类和方法。

<Callout type="info">
  将 `https://mg.foahh.com/llms.txt` 提供给助手，它可以从这里出发，按需抓取所需的文档页面。
</Callout>

## 示例工作流

以 Claude Code 为例，可以按如下步骤使用：

1. 在项目目录中启动 Claude Code。
2. 让 Claude 找到已安装包的路径并读取源码：

   ```
   找到 margrete_rpc 包的安装路径并阅读其源码
   ```

3. 描述你想要实现的功能，例如：

   ```
   帮我写一个脚本，找出谱面中所有时间小于第 100 拍的 Tap 物件并删除它们
   ```

助手会根据源码决定自动需要干的事情。
