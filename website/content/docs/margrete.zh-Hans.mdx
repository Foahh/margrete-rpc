2. 创建一个名为 `example.py` 的文件，并运行这段脚本：

   ```python
   from margrete_rpc import Margrete
   from margrete_rpc.chart.notes import Tap

   with Margrete() as m:
       m.ping()
       status = m.status()
       print(status.server_version)
       print(status.server_name)
       print(status.instance_id)

       with m.open_edit() as tx:
           tx.chart.notes.append(Tap(t=0, x=0, w=4))
           # 这个代码块正常退出后，修改会被应用
   ```

   ```bash
   python example.py
   ```

   这段代码会连接到 Margrete，打印插件状态，并向谱面中添加一个 `Tap` 物件。

   不传入参数时，`Margrete()` 会自动检测正在运行的插件实例。通常情况下，如果只打开了一个 Margrete 窗口，直接使用 `Margrete()` 即可。如果同时运行了多个实例，请参阅 [多个 Margrete](/docs/advanced/handle-multi-margrete)。

## 撤销和重做

你可以从 `Margrete()` 触发撤销和重做：

```python
with Margrete() as m:
    m.undo()  # 如果撤销了内容，返回 True
    m.redo()  # 如果重做了内容，返回 True
```

<Callout type="warn">
  Margrete 的撤销操作有一些限制。详情请参阅 [限制](/docs/limitations#撤销物件删除)。
</Callout>
