通常使用 `open_edit()` 编辑谱面：

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.notes import Tap

with Margrete() as m:
    with m.open_edit() as tx:
        tx.chart.notes.append(Tap(t=(0, 0), x=4, w=4))
```

当 `open_edit()` 的代码块正常退出时，编辑会发送到 Margrete。如果这个代码块抛出异常，则不会应用任何修改。

## 如何理解

可以把 `open_edit()` 理解为一个四步流程：

1. **读取** - Margrete 将当前的谱面和其他信息发送给 Python。
2. **解析** - Python 读取谱面，将其转换为 Python 里可以使用的对象，例如 [`Tap`](/docs/reference/chart/notes/ground/Tap)
   和 [`Slide`](/docs/reference/chart/notes/long/Slide)。
3. **编辑** - 你的代码在此时发挥作用。
4. **应用** - 退出 `open_edit()` 的代码块后，Python 将对比一开始收到的谱面，尝试了解你修改了什么，并将编辑发送给 Margrete。

如果你想读取或修改谱面，请使用 `open_edit()` 返回的 [`tx`](/docs/reference/transaction/EditTransaction) 中的这三项：

| 对象              | 用途                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------ |
| `tx.chart.notes`  | 包含所有物件的列表，例如 `Tap`、`Slide`、`AirCrush`。 |
| `tx.chart.events` | 包含所有事件的列表，例如变 BPM、变拍、变速。                |
| `tx.current_tick` | 当前的时间。                                        |

`tx.chart.events` 会按类型组织谱面 events。关于如何添加、修改和过滤每个 event list，见 [Events](/docs/basic/events)：

| 列表                         | 包含内容                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `tx.chart.events.bpm`        | [`BpmEvent(t, bpm)`](/docs/reference/chart/events/BpmEvent) tempo changes。                                   |
| `tx.chart.events.beat`       | [`BeatEvent(bar, beats_per_bar, beat_unit)`](/docs/reference/chart/events/BeatEvent) time-signature changes。 |
| `tx.chart.events.til`        | [`TimelineSpeedEvent(til, t, speed)`](/docs/reference/chart/events/TimelineSpeedEvent) scroll-speed changes。 |
| `tx.chart.events.note_speed` | [`NoteSpeedEvent(t, speed)`](/docs/reference/chart/events/NoteSpeedEvent) note-speed changes。                |

## 实用示例

### 读取谱面

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.notes import Tap

with Margrete() as m:
    with m.open_edit() as tx:
        for note in tx.chart.notes:
            if isinstance(note, Tap):
                print(f"Tap at tick {note.t}, lane {note.x}")

        for event in tx.chart.events.bpm:
            print(f"BPM {event.bpm} at tick {event.t}")

        for event in tx.chart.events.beat:
            print(f"Bar {event.bar}: {event.beats_per_bar}/{event.beat_unit}")
```

### 在当前 cursor 处添加 note

如果希望编辑发生在 Margrete 中红色 playhead 所在位置，请使用 `tx.current_tick`。

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.notes import Tap

with Margrete() as m:
    with m.open_edit() as tx:
        tx.chart.notes.append(Tap(t=tx.current_tick, x=4, w=4))
```

### 将所有 notes 向右移动两个 lanes

Notes 是普通对象。Transform methods 会原地修改它们。示例见 [Note Transforms](/docs/basic/note-transforms)，准确签名见 [`Note`](/docs/reference/chart/notes/shared/Note#functions) reference。

```python
with m.open_edit() as tx:
    for note in tx.chart.notes:
        note.shift(x=2)
```

Transforms 也会更新 long-note joints 和 attached air notes，所以它不只适用于 taps。

### 删除某个 lane 范围内的 notes

将过滤后的列表重新赋值给 `tx.chart.notes`。

```python
with m.open_edit() as tx:
    # 只保留从 lane 4 或更靠右开始的 notes。
    tx.chart.notes = [note for note in tx.chart.notes if note.x >= 4]
```

<Callout type="warn">
  删除 notes 的 transactions 在 Undo 时存在已知问题。详情见
  [Limitations](/docs/limitations#undo-and-note-deletion)。
</Callout>

### 用新 notes 替换所有 notes

当脚本有意替换谱面中的所有 notes 时，请使用 `replace_all=True`。

```python
from margrete_rpc.chart.notes import Tap

with m.open_edit(replace_all=True) as tx:
    tx.chart.notes = [
        Tap(t=(0, 0), x=0, w=4),
        Tap(t=(0, 1), x=4, w=4),
        Tap(t=(0, 2), x=8, w=4),
        Tap(t=(0, 3), x=12, w=4),
    ]
```

### 编辑 BPM 和 speed events

Events 位于 `tx.chart.events` 下。你可以像编辑 notes 一样检查、追加、过滤或修改这些 lists。

```python
from margrete_rpc.chart.events import BpmEvent, TimelineSpeedEvent

with m.open_edit() as tx:
    tx.chart.events.bpm.append(BpmEvent(t=0, bpm=180.0))

    # Timeline speed event：timeline id、tick、speed multiplier。
    tx.chart.events.til.append(TimelineSpeedEvent(til=0, t=(4 * 1920), speed=1.5))

    # 删除 4/4 谱面中 bar 8 之后的 note-speed events。
    tx.chart.events.note_speed = [
        event for event in tx.chart.events.note_speed if event.t < 8 * 4 * 1920
    ]
```

### 安全检查 unsupported notes

默认情况下，Python API 会把可识别的 [`RawNote`](/docs/reference/chart/notes/raw/RawNote) 对象解析为 [`Note`](/docs/reference/chart/notes/shared/Note) 对象，例如 [`Tap`](/docs/reference/chart/notes/ground/Tap) 或 [`Slide`](/docs/reference/chart/notes/long/Slide)。如果遇到 unsupported note，它会保留为 `RawNote`，而不是丢弃。

```python
from margrete_rpc.chart.notes import RawNote

with m.open_edit() as tx:
    for note in tx.chart.notes:
        if isinstance(note, RawNote):
            print(note.type, note.t, note.x, note.w)
```

如果希望所有 notes 都保持底层 raw 形式，请传入 `raw_notes=True`。

```python
with m.open_edit(raw_notes=True) as tx:
    for note in tx.chart.notes:
        print(note.type, note.t, note.x, note.w)
```

## Cursor position

Cursor 是编辑器中的红色 playhead line。如果不熟悉它，可以查看 [Margrete docs](https://umgr.inonote.jp/en/margrete/getting-started/user-interface)。

<ImageZoom src={CurrentTickPlayhead} alt="Current cursor playhead in Margrete" width="300" />

如果需要在 transaction 外获取实时 cursor position，请使用 [`m.current_tick()`](/docs/reference/client/Margrete#functions)：

```python
tick = m.current_tick()
```

在 transaction 内，请使用 `tx.current_tick`。它在 transaction 打开时捕获，在代码块运行期间不会变化：

```python
with m.open_edit() as tx:
    tick = tx.current_tick
```

## Undo 和 redo

你可以从 Python 触发 undo 和 redo：

```python
m.undo()  # 如果撤销了内容，返回 True
m.redo()  # 如果重做了内容，返回 True
```

## `open_edit` 选项

| 参数                         | 默认值  | 使用场景                                                                                                                           |
| ---------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `snapshot`                   | `True`  | 你想读取当前谱面，并在退出时只发送差异。这是普通编辑的默认方式。                                                                   |
| `replace_all`                | `False` | 你希望最终的 `tx.chart.notes` 列表替换谱面中的所有 notes。适合生成式重写。                                                         |
| `raw_notes`                  | `False` | 你希望每个 note 都是 `RawNote`，而不是 `Note` 对象。                                                                               |
| `event_scan_lookahead_ticks` | `None`  | 你需要扫描距离最后一个 note 更远的 scroll-speed events。`None` 使用 server 默认值。                                                |
| `event_scan_til_ids`         | `None`  | 你需要控制扫描哪些 timelines 的 scroll-speed events。`None` 扫描承载 notes 的 timelines；`[]` 扫描所有默认 timelines `0` 到 `15`。 |

常见写法：

```python
# 普通编辑：进入时 snapshot，退出时发送 diff。
with m.open_edit() as tx:
    ...

# 完整重写 notes。
with m.open_edit(replace_all=True) as tx:
    tx.chart.notes = build_notes()

# 底层 raw 编辑。
with m.open_edit(raw_notes=True) as tx:
    ...

# 不先读取已有 notes，直接插入生成的 notes。
with m.open_edit(snapshot=False) as tx:
    tx.chart.notes = build_notes()

# 读取最后一个 note 之后更远位置的 scroll-speed events。
with m.open_edit(event_scan_lookahead_ticks=1920 * 16) as tx:
    ...

# 扫描指定 timelines 的 scroll-speed events。
with m.open_edit(event_scan_til_ids=[0, 1, 2]) as tx:
    ...
```
