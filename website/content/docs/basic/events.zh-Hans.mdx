## 如何理解

事件包括变 BPM, 变拍（time-signature）, 谱面变速（scroll-speed）和物件变速（note-speed）。

`tx.chart` 有四个事件列表：

| 列表              | 控制内容                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `tx.chart.bpms`   | [`BpmEvent`](/docs/reference/chart/events/BpmEvent) 控制歌曲 BPM 变化。                           |
| `tx.chart.beats`  | [`BeatEvent`](/docs/reference/chart/events/BeatEvent) 控制拍号变化。                              |
| `tx.chart.tils`   | [`TimelineSpeedEvent`](/docs/reference/chart/events/TimelineSpeedEvent) 控制指定 TIL 的谱面变速。 |
| `tx.chart.speeds` | [`NoteSpeedEvent`](/docs/reference/chart/events/NoteSpeedEvent) 控制指定物件的流速。              |

```python
with m.open_edit() as tx:
    # 读取
    for event in tx.chart.bpms:
        print(event.t, event.bpm)

    # 修改
    tx.chart.bpms[0].bpm = 185.0

    # 过滤
    tx.chart.speeds = [
        event for event in tx.chart.speeds if event.t < 7680
    ]
```

## BPM 事件

使用 [`BpmEvent(t, bpm)`](/docs/reference/chart/events/BpmEvent) 从指定时间开始设置 BPM。

```python
from margrete_rpc.chart.events import BpmEvent

with m.open_edit() as tx:
    tx.chart.bpms.append(BpmEvent(t=0, bpm=180.0))
    tx.chart.bpms.append(BpmEvent(t=(1, 0, 0), bpm=200.0))
```

如果想更新已有的 BPM 事件，找到它并修改 `bpm`：

```python
with m.open_edit() as tx:
    for event in tx.chart.bpms:
        if event.t == 0:
            event.bpm = 185.0
            break
```

## 变拍事件

使用 [`BeatEvent(bar, beats_per_bar, beat_unit)`](/docs/reference/chart/events/BeatEvent) 表示拍号。和多数事件不同，变拍事件按小节编号放置，而不是按时间放置。

```python
from margrete_rpc.chart.events import BeatEvent

with m.open_edit() as tx:
    tx.chart.beats.append(BeatEvent(0, 4, 4))   # 从第 1 小节开始变为 4/4
    tx.chart.beats.append(BeatEvent(16, 3, 4))  # 从第 17 小节开始变为 3/4
```

添加变拍事件后，同一个 `open_edit()` 里的音符位置（Position）会自动使用新的拍号。详情见[时间与音符位置](/docs/basic/time-position#positions)。

```python
from margrete_rpc.chart.events import BeatEvent
from margrete_rpc.chart.notes import Tap

with m.open_edit(snapshot=False) as tx:
    tx.chart.beats.append(BeatEvent(0, 3, 4))

    # 这里表示 3/4 的第 4 小节。
    tx.chart.notes.append(Tap(t=(4, 0), x=4, w=4))
```

## 删除事件

事件列表就是普通的 Python 列表，因此通常可以用过滤列表的方式删除事件：

```python
with m.open_edit() as tx:
    # 删除 tick 7680 之后的所有 BPM 事件。
    tx.chart.bpms = [
        event for event in tx.chart.bpms if event.t <= 7680
    ]

    # 删除 TIL 0 上的所有谱面变速事件。
    tx.chart.tils = [
        event for event in tx.chart.tils if event.til != 0
    ]
```

## 事件去重

如果两个同类型的事件在同一位置，发送编辑时列表中靠后的项目会生效：

| 事件类型      | 同一位置           |
| ------------- | ------------------ |
| BPM，物件变速 | 同一个 tick        |
| 变拍          | 同一个小节         |
| 变速          | 同一个 tick 和 TIL |

```python
with m.open_edit() as tx:
    tx.chart.bpms.append(BpmEvent(t=0, bpm=180.0))
    tx.chart.bpms.append(BpmEvent(t=0, bpm=185.0))  # 这个会生效
```
