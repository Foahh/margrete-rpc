title: Note Transforms
description: Shift、align、flip、scale、clone、split、merge 和 convert notes。
---

Transforms 是 [`Note`](/docs/reference/chart/notes/shared/Note) 对象上的方法。当你想调整已有 notes，而不是手动重建它们时，可以使用这些方法。本指南展示常见模式；核心 transform method 的准确签名见 [`Note` functions reference](/docs/reference/chart/notes/shared/Note#functions)。这些方法适用的 note constructors 见 [Notes](/docs/basic/notes)。

```python
from margrete_rpc import Margrete

with Margrete() as m:
    with m.open_edit() as tx:
        for note in tx.chart.notes:
            note.shift(x=2)
```

当 `with{:py}` 代码块正常退出时，编辑会发送到 Margrete。如果代码块抛出异常，则不会应用任何修改。

## 原地修改或克隆

大多数 transform methods 都有两种形式：

| 原地修改     | 克隆             | 含义                                   |
| ------------ | ---------------- | -------------------------------------- |
| `shift(...)` | `shifted(...)`   | 修改当前 note，或返回修改后的副本。    |
| `scale(...)` | `scaled(...)`    | 修改当前 note，或返回修改后的副本。    |
| `align(...)` | `aligned(...)`   | 修改当前 note，或返回修改后的副本。    |
| `flip(...)`  | `flipped(...)`   | 修改当前 note，或返回修改后的副本。    |
| `clamp(...)` | `clamped_w(...)` | 修改当前 note，或返回修改后的副本。    |
| n/a          | `converted(...)` | 返回复制了 geometry 的兼容 note type。 |
| n/a          | `clone()`        | 返回 deep copy。                       |

直接编辑 `tx.chart.notes` 时，使用原地修改形式：

```python
with m.open_edit() as tx:
    for note in tx.chart.notes:
        note.shift(x=2)
```

如果想保留原 note，请使用克隆形式：

```python
with m.open_edit() as tx:
    copies = [note.shifted(t=1920, x=4) for note in tx.chart.notes]
    tx.chart.notes.extend(copies)
```

## Shift notes

[`shift()`](/docs/reference/chart/notes/shared/Note#functions) 会给 note 字段增加 delta。

```python
note.shift(t=1920)  # 向后移动一个 beat
note.shift(x=2)     # 向右移动 2 个 lanes
note.shift(w=1)     # 宽度增加 1 个 lane
note.shift(h=20)    # air height 增加 20
```

对 `t` 来说，也可以传入 [`Position`](/docs/reference/chart/time/Position) tuple。它的解析方式与 [constructor positions](/docs/basic/notes#positioning) 相同。

```python
note.shift(t=(1, 0))  # 在当前 time-signature context 下移动一个 bar
```

每个 delta 也可以是一个 callable，接收当前值：

```python
note.shift(x=lambda x: 15 - x)
note.shift(w=lambda w: max(1, w - 1))
```

## 将 notes 对齐到 grid

[`align()`](/docs/reference/chart/notes/shared/Note#functions) 会把 timing 吸附到 grid interval。

```python
with m.open_edit() as tx:
    for note in tx.chart.notes:
        note.align((1, 384))
```

`mode` 控制吸附方式：

| Mode      | 行为                                 |
| --------- | ------------------------------------ |
| `"round"` | 吸附到最近的 grid line。这是默认值。 |
| `"floor"` | 向后吸附到前一个 grid line。         |
| `"ceil"`  | 向前吸附到下一个 grid line。         |

```python
note.align((1, 384), mode="floor")
```

## Flip notes

[`flip()`](/docs/reference/chart/notes/shared/Note#functions) 会让 notes 沿水平方向镜像。默认 field width 是 16 lanes。

```python
note.flip()
```

对于 `x=2, w=4` 的 note，在 16-lane field 中 flip 后会移动到 `x=10, w=4`。

如果 lane width 不同，请使用 `field=`：

```python
note.flip(field=8)
```

Directional notes 也会被镜像。例如，`"left"` flicks 会变成 `"right"` flicks。

## Clamp lane

[`clamp()`](/docs/reference/chart/notes/shared/Note#functions) 会把 note geometry 限制在 lane range 内，默认是 `[0, 16)`。

```python
note.clamp()  # 默认 left=0, right=16
```

右边界是 exclusive，因此 `right=16` 表示 note 必须在 lane 16 之前结束。另外，宽度永远不会被 clamp 到小于 `1`。

这在 shift 或 flip 生成的 notes 后很有用：

```python
for note in tx.chart.notes:
    note.shift(x=-2).clamp(left=0, right=16)
```

## Scale timing

[`scale()`](/docs/reference/chart/notes/shared/Note#functions) 会围绕 pivot tick 缩放 timing，pivot 默认是 `0`。

```python
note.scale(2.0, pivot=0)
```

当 `factor=2.0` 时，每个 point 都会移动到距离 pivot 两倍远的位置。当 `factor=0.5` 时，每个 point 都会向 pivot 靠近一半。

```python
for note in tx.chart.notes:
    note.scale(0.5)
```

`pivot` 可以是 tick，也可以是 `Position` tuple：

```python
note.scale(1.5, pivot=(4, 0))
```

## Clone notes

[`clone()`](/docs/reference/chart/notes/shared/Note#functions) 会创建 deep copy。复制 notes 时可以使用它。

```python
with m.open_edit() as tx:
    copies = []

    for note in tx.chart.notes:
        copies.append(note.clone().shift(t=1920))

    tx.chart.notes.extend(copies)
```

## Split slides

[`split()`](/docs/reference/chart/notes/transform#functions) 会把 slide-like note 分成两个 notes。它支持 [`Slide`](/docs/reference/chart/notes/long/Slide)、[`AirSlide`](/docs/reference/chart/notes/air/AirSlide) 和 [`AirCrush`](/docs/reference/chart/notes/long/AirCrush)。

```python
from margrete_rpc.chart.notes import Slide, split

slide = (
    Slide(t=(0, 0), x=0, w=4)
    .with_ctrl(t=(0, 2), x=6, w=4)  # joints[0]
    .with_step(t=(1, 0), x=8, w=4)  # joints[1]
)

left, right = split(slide, (0, 2))
left, right = split(slide, slide.joints[0])
```

Split point 可以是 `Position` tuple、raw tick，或 note 的某个 joint。Split 必须发生在 note 内部，不能位于 final joint。

## Merge slides

[`merge()`](/docs/reference/chart/notes/transform#functions) 会合并连续的同类型 slide-like notes。它支持 [`Slide`](/docs/reference/chart/notes/long/Slide)、[`AirSlide`](/docs/reference/chart/notes/air/AirSlide) 和 [`AirCrush`](/docs/reference/chart/notes/long/AirCrush)。

```python
from margrete_rpc.chart.notes import Slide, merge

first = Slide(t=(0, 0), x=0, w=4).with_step(t=(1, 0), x=4, w=4)
second = Slide(t=(1, 0), x=4, w=4).with_step(t=(2, 0), x=8, w=4)

combined = merge([first, second])
```

这些 notes 不能重叠，且传给 `merge()` 的所有 notes 必须是同一类型。

## Convert notes

如果想把一个 note 重建为另一个兼容 note type，而不想手动复制 timing 和 geometry，请使用 `converted()`。它记录在支持该功能的具体 note classes 上，例如 [`Tap`](/docs/reference/chart/notes/ground/Tap#functions)、[`Hold`](/docs/reference/chart/notes/long/Hold#functions) 和 [`AirSlide`](/docs/reference/chart/notes/air/AirSlide#functions)。

`converted()` 总是返回一个新 note，不会修改原 note。目标类型需要的字段可以通过 keyword overrides 传入，例如 `dir`、`h`、`gap` 或 `color`。

| Source note | Convertible targets                        |
| ----------- | ------------------------------------------ |
| `Tap`       | `Extap`, `Flick`, `Damage`                 |
| `Extap`     | `Tap`, `Flick`, `Damage`                   |
| `Flick`     | `Tap`, `Extap`, `Damage`                   |
| `Damage`    | `Tap`, `Extap`, `Flick`                    |
| `Hold`      | `Slide`, `AirSlide`, `AirCrush`, `AirHold` |
| `Slide`     | `AirSlide`, `AirCrush`                     |
| `AirSlide`  | `Slide`, `AirCrush`                        |
| `AirCrush`  | `Slide`, `AirSlide`                        |

### Ground note conversions

Ground notes 可以在 `Tap`、`Flick`、`Extap` 和 `Damage` 之间转换。

```python
from margrete_rpc.chart.notes import Damage, Extap, Flick, Tap

tap = Tap(t=(0, 0), x=4, w=4)

flick = tap.converted(Flick, dir="right")
extap = flick.converted(Extap, dir="up")
damage = extap.converted(Damage)
tap_again = damage.converted(Tap)
```

在 ground note types 之间转换时，attached air notes 会被复制。

```python
from margrete_rpc.chart.notes import Air

tap = Tap(t=(0, 0), x=4, w=4).with_air(Air("up", t=(0, 0), x=4, w=4))
flick = tap.converted(Flick, dir="left")
```

### Long note conversions

Long notes 会把 begin point 和 joints 复制到目标类型。

```python
from margrete_rpc.chart.notes import AirCrush, AirSlide, Hold, Slide

hold = Hold(t=(0, 0), x=4, w=4).with_step(t=(1, 0), x=8, w=4)

slide = hold.converted(Slide)
air_slide = hold.converted(AirSlide, h=80)
crush = slide.converted(AirCrush, h=80, gap=(1, 8), color="green")
```

### Air-long conversions

`AirSlide` 和 `AirCrush` 可以转换回兼容的 long-note types。

```python
from margrete_rpc.chart.notes import AirCrush, AirSlide, Slide

air_slide = (
    AirSlide(t=(0, 0), x=4, w=4, h=80)
    .with_ctrl(t=(0, 2), x=6, w=4, h=100)
    .with_step(t=(1, 0), x=8, w=4, h=80)
)

ground_slide = air_slide.converted(Slide)
crush = air_slide.converted(AirCrush, gap=(1, 8), color="blue")
back_to_air_slide = crush.converted(AirSlide)
```

`Hold` 也可以转换为 `AirHold`：

```python
from margrete_rpc.chart.notes import AirHold, Hold

hold = Hold(t=(0, 0), x=4, w=4).with_step(t=(1, 0), x=4, w=4)
air_hold = hold.converted(AirHold, h=80)
```
