在这个例子里，脚本向谱面放置了三个 Tap。一个物件通常会包含这些字段：

| 字段 | 含义                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| `t`  | 物件的时间。详细请见 [时间与音符位置](/docs/basic/time-position)。                                                          |
| `p`  | 物件的音符位置（`Position`）。例如 `(1, 0, 0)` 表示第 2 小节第 1 拍。详细请见 [时间与音符位置](/docs/basic/time-position)。 |
| `x`  | 物件的轨道位置。通常的范围是 `0` 到 `15`。                                                                                  |
| `w`  | 物件的宽度。                                                                                                                |
| `h`  | Air 的高度。只有 Air 长条和 AirCrush 会使用它。                                                                             |

## 地面类物件

地面物件通常都有 `t`、`x` 和 `w` 字段。

### Tap

```python
from margrete_rpc.chart.notes import Tap

note = Tap(t=(0, 0), x=4, w=4)
```

### Flick

`Flick` 额外有一个 `dir` 字段，用来表示 Flick 的滑动方向。

```python
from margrete_rpc.chart.notes import Flick, FlickDirection

left = Flick(t=(0, 0), x=4, w=4, dir=FlickDirection.LEFT)
right = Flick(t=(0, 1), x=4, w=4, dir="right")
auto = Flick(t=(0, 2), x=4, w=4)  # 默认为 "auto"
```

`dir` 接受 [`FlickDirection`](/docs/reference/chart/notes/direction/FlickDirection)，也可以直接传入表示方向的字符串：`"auto"`, `"left"` 和 `"right"`。

### Extap

`Extap` 额外有一个 `dir` 字段，用来表示其爆裂特效的方向。

```python
from margrete_rpc.chart.notes import Extap, ExtapDirection

up = Extap(t=(0, 0), x=4, w=4, dir=ExtapDirection.UP)
spin = Extap(t=(0, 1), x=4, w=4, dir="rotate_left")
```

`dir` 接受 [`ExtapDirection`](/docs/reference/chart/notes/direction/ExtapDirection)，也可以直接传入表示方向的字符串：`"up"`, `"down"`, `"center"`, `"left"`, `"right"`, `"rotate_left"`, `"rotate_right"`, `"in_out"` 和 `"out_in"`。

### Damage

```python
from margrete_rpc.chart.notes import Damage

note = Damage(t=(0, 0), x=4, w=4)
```

## 长条类物件

长条物件有一个起点，以及一个或多个节点。

如果要直接修改当前长条物件，请使用 `add_step()` 和 `add_ctrl()` 添加节点：

```python
slide = Slide(t=(0, 0), x=0, w=4)
slide.add_ctrl(t=(0, 2), x=8, w=4)
slide.add_step(t=(1, 0), x=4, w=4)
```

`with_step()` 和 `with_ctrl()` 会返回当前长条物件的深拷贝，适合需要保留原物件不变的场景：

```python
from margrete_rpc.chart.notes import Slide

slide = (
    Slide(t=(0, 0), x=0, w=4)
    .with_ctrl(t=(0, 2), x=8, w=4)
    .with_step(t=(1, 0), x=4, w=4)
)
```

节点必须按时间递增的顺序添加。长条物件在发送给 Margrete 前，必须至少有一个节点。

### Hold

`Hold` 从起点开始，并在一个 Step 节点结束。

```python
from margrete_rpc.chart.notes import Hold

hold = Hold(t=(0, 0), x=4, w=4).with_step(t=(1, 0), x=4, w=4)
```

### Slide

`Slide` 有多个 Step 和 Control 节点。

```python
from margrete_rpc.chart.notes import Slide

slide = (
    Slide(t=(0, 0), x=0, w=4)
    .with_ctrl(t=(0, 2), x=8, w=4)
    .with_step(t=(1, 0), x=4, w=4)
)
```

发送给 Margrete 时，最后一个节点会自动变成 Step。

### AirCrush

`AirCrush` 额外包含这些字段：

| 字段       | 含义                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| `h`        | 高度。                                                                                                          |
| `gap`      | Step 间隔。详细请见 [时间与音符位置](/docs/basic/time-position)。                                               |
| `interval` | Step 间隔的时值表示。例如 `gap=(1, 8)` 表示一个八分音符。详细请见 [时间与音符位置](/docs/basic/time-position)。 |
| `color`    | 线条颜色，可以是 [`ColorValue`](/docs/reference/chart/notes/color/ColorValue)，也可以是表示颜色的字符串。       |

`color` 接受的字符串值包括 `"default"`, `"red"`, `"orange"`, `"yellow"`, `"green"`, `"sky"`, `"blue"`, `"violet"`, `"pink"`, `"white"`, `"black"`, `"grass"`, `"sky_blue"`, `"cobalt_blue"`, `"purple"` 和 `"none"`。

`gap` 同时有特殊的数值：

| 常量                     | 值           | 效果                     |
| ------------------------ | ------------ | ------------------------ |
| `AIRCRUSH_GAP_TRACELIKE` | `0`          | AirTrace（只显示线条）。 |
| `AIRCRUSH_GAP_HEADONLY`  | `0x7FFFFFFF` | 只有头部 Step。          |

```python
from margrete_rpc.chart.notes import AirCrush

crush = (
    AirCrush(t=(0, 0), x=4, w=4, h=80, gap=(1, 8), color="blue")
    .with_ctrl(t=(0, 2), x=6, w=4, h=100)
    .with_ctrl(t=(1, 0), x=8, w=4, h=80)
)
```

## Air 类物件

Air 类物件需要附着到地面物件上。

你可以直接给 `.air` 赋值：

```python
from margrete_rpc.chart.notes import Air, AirDirection, Tap

tap = Tap(t=(0, 0), x=4, w=4)
air = Air(AirDirection.UP, t=(0, 0), x=4, w=4)

tap.air = air
```

也可以使用 [`add_air()`](/docs/reference/chart/notes/air/_AirAttachable)：

```python
tap.add_air(air)
```

[`with_air()`](/docs/reference/chart/notes/air/_AirAttachable) 会返回当前地面物件的深拷贝，适合需要保留原物件不变的场景：

```python
tap_with_air = tap.with_air(Air("up", t=(0, 0), x=4, w=4))  # 原来的 Tap 不变
```

Air 类物件的位置必须与被附着的物件相匹配：

- 对地面物件来说，它必须匹配其 `t`、`x` 和 `w`。
- 对长条物件来说，它必须匹配其最后一个节点的 `t`、`x` 和 `w`。

### 单独的 Air

`Air` 物件额外有一个 `dir` 字段，用来表示它的朝向。
它还有一个 `inverted` 字段，设为 `True` 可以反色。

```python
from margrete_rpc.chart.notes import Air, AirDirection, Tap
air = Air(AirDirection.UP, t=(0, 0), x=4, w=4)
air = Air("up", t=(0, 0), x=4, w=4)
```

`dir` 接受 [`AirDirection`](/docs/reference/chart/notes/direction/AirDirection)，也可以直接传入表示方向的字符串：`"up"`, `"down"`, `"up_left"`, `"up_right"`, `"down_left"` 和 `"down_right"`。

### AirHold

`AirHold` 的用法与 `Hold` 相同，只是额外增加了 `h` 字段：
它还有一个 `inverted` 字段，设为 `True` 可以反色。

```python
from margrete_rpc.chart.notes import AirHold, Hold

hold = Hold(t=(0, 0), x=4, w=4).with_step(t=(1, 0), x=6, w=4)

hold.add_air(
    AirHold(t=(1, 0), x=6, w=4, h=80)
    .with_step(t=(1, 2), x=6, w=4, h=120)
)
```

### AirSlide

`AirSlide` 的用法与 `Slide` 相同，只是额外增加了 `h` 字段：
它还有一个 `inverted` 字段，设为 `True` 可以反色。

```python
from margrete_rpc.chart.notes import AirSlide, Slide

slide = Slide(t=(0, 0), x=0, w=4).with_step(t=(1, 0), x=8, w=4)

slide.add_air(
    AirSlide(t=(1, 0), x=8, w=4, h=80)
    .with_ctrl(t=(1, 2), x=10, w=4, h=120)
    .with_step(t=(2, 0), x=8, w=4, h=80)
)
```

## 验证物件合法

`open_edit()` 正常结束时，Python 会验证所有谱面物件，确保它们符合写谱规则。如果想更早发现无效物件，可以手动调用 [`note.validate()`](/docs/reference/chart/notes/shared/Note)。

```python
note.validate()  # 无效时抛出 ValueError
```

常见验证失败包括：

- 物件宽度为 0 或负数，
- 长条物件的节点没有按时间递增，
- 长条物件缺少节点，
- Air 类物件的 `t`/`x`/`w` 与被附着的物件不匹配。
