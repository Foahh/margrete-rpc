Python API 使用下面这些模型来表示时间。所有和时间有关的 API 都使用这些模型。

## Ticks

最底层的时间单位是 **tick**。在 Margrete 中，全音符的分辨率是 [`TICK_RESOLUTION`](/docs/reference/chart/time)（1920）tick，因此常见音符时值对应的 tick 数如下：

<div className="prose-no-margin flex gap-2 [&_.my-6]:my-0 [&_figure]:my-0 [&_img]:my-0">

    <div className="flex-1">

    | 时值              | Tick |
    | ----------------- | ---- |
    | 全音符 (1/1)      | 1920 |
    | 二分音符 (1/2)    | 960  |
    | 四分音符 (1/4)    | 480  |
    | 八分音符 (1/8)    | 240  |
    | 十六分音符 (1/16) | 120  |

    </div>

    <ImageZoom src={NoteTickListImage} alt="Note tick list" width="205" />

</div>

```python
from margrete_rpc.chart.notes import Tap
from margrete_rpc.chart.time import TICK_RESOLUTION

tap = Tap(t=TICK_RESOLUTION // 4, x=0, w=4)  # 4/4 中的第 1 小节第 2 拍
print(tap.t)  # 480
```

任何接受时间参数的地方，例如 `t=`，都可以直接传入 tick。

## 音符位置

直接计算 tick 往往不够直观。音符位置（[`Position`](/docs/reference/chart/time/Position)）允许你用小节和拍来表示时间：

| 形式                  | 含义                   |
| --------------------- | ---------------------- |
| `(bar,)`              | 小节开头               |
| `(bar, beat)`         | 小节内的某一拍         |
| `(bar, beat, offset)` | 某一拍内加上 tick 偏移 |

注意，所有字段都从 0 开始计数。例如，第 1 小节第 1 拍表示为 `(0, 0, 0)`。

```
以 4/4 为例：

bar 1, beat 1 ── bar 1, beat 2 ── bar 1, beat 3 ── bar 1, beat 4
tick 0           tick 480         tick 960         tick 1440
```

任何接受时间参数的 API 都可以接受音符位置（`Position`）元组：

```python
from margrete_rpc.chart.notes import Tap

Tap(t=(2,), x=0, w=4)         # 第 3 小节第 1 拍
Tap(t=(2, 1), x=0, w=4)       # 第 3 小节第 2 拍
Tap(t=(2, 1, 240), x=0, w=4)  # 第 3 小节第 2 拍，再向后偏移 240 tick
```

在 `open_edit()` 代码块内，音符位置（`Position`）元组会根据谱面实际的拍号进行解析：

```python
from margrete_rpc.chart.events import BeatEvent
from margrete_rpc.chart.notes import Tap

with m.open_edit(snapshot=False) as tx:
    tx.chart.beats.append(BeatEvent(0, 2, 4))  # 第 1 小节开始 2/4
    tx.chart.beats.append(BeatEvent(1, 1, 4))  # 第 2 小节开始 1/4
    tx.chart.notes.append(Tap(t=(2, 0), x=0, w=4))
```

这里的 `(2, 0)` 仍然表示第 3 小节开头，但换算得到的 tick 会受到前面拍号的影响。

### 手动转换

当你需要手动转换数值时，可以使用 [`tick_to_pos`](/docs/reference/chart/time) 和 [`pos_to_tick`](/docs/reference/chart/time)：

```python
from margrete_rpc.chart.events import BeatEvent
from margrete_rpc.chart.time import pos_to_tick, tick_to_pos

beat_events = [BeatEvent(0, 4, 4)]

pos = tick_to_pos(1920, beat_events=beat_events)
print(pos)  # Position(bar=1, beat=0, offset=0)

tick = pos_to_tick(2, 3, beat_events=beat_events)
print(tick)  # 2 * 1920 + 3 * 480 = 5280
```

如果没有传入 `beat_events`，这些转换函数在 `open_edit()` 内会使用当前谱面的拍号进行计算；在 `open_edit()` 外，则会按默认 4/4 拍计算。

如果代码在 `open_edit()` 外运行，并且谱面不是普通 4/4 拍，请显式传入拍号事件：

```python
from margrete_rpc.chart.events import BeatEvent
from margrete_rpc.chart.time import pos_to_tick

beats = [BeatEvent(0, 3, 4)]  # 3/4
tick = pos_to_tick(10, 0, 0, beat_events=beats)
```

## 时值

音符位置描述某个内容从**哪里**开始，时值（[`Division`](/docs/reference/chart/time/Division)）描述它持续**多久**。

使用 [`div_to_tick(numerator, denominator)`](/docs/reference/chart/time) 可以将音符时值转换为 tick：

```python
from margrete_rpc.chart.time import div_to_tick, tick_to_div

quarter = div_to_tick(1, 4)  # 480 ticks
eighth = div_to_tick(1, 8)   # 240 ticks
dotted = div_to_tick(3, 4)   # 1440 ticks（三个四分音符）

division = tick_to_div(480)    # Division(numerator=1, denominator=4)
```

一些 API 也可以接受时值（`Division`）元组，例如 `align()` 或 AirCrush 的 `gap`：

```python
# 将物件的开始位置吸附到最近的八分音符
note.align((1, 8))

# AirCrush 的 Step 间隔为十六分音符
AirCrush(t=0, x=0, w=4, h=4, gap=(1, 16), ...)
```

<Callout type="info">
  小于 `1` tick (`1/1920`) 的正时值（例如 `1/2048`）会被转换为 `1` tick。
</Callout>

## 使用 TimeCalculator

如果需要多次手动转换时间，可以先创建一个 [`TimeCalculator`](/docs/reference/chart/time/TimeCalculator)，而不是每次调用辅助函数时都传入 `beat_events`：

```python
from margrete_rpc.chart.time import TimeCalculator

calc = TimeCalculator(tx.chart.beats)
pos = calc.tick_to_pos(3840)
tick = calc.pos_to_tick(1, 2, 0)
```

通常只有在 `open_edit()` 外运行的代码才需要 `TimeCalculator`。在 `open_edit()` 内，会自动使用谱面的拍号计算 tick。
