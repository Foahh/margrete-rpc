---
title: Sketch Slides
description: Generate slides, air slides, and air-crush paths with curve utilities.
---

The utilities in `margrete_rpc.chart.util` help you sketch complex slide pattern.
Common ways to use them: draw a path as a `Curve`, then materialize it as
a `Slide`, `AirSlide`, or `AirCrush`.

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.util import Curve

m = Margrete()

with m.open_edit() as tx:
    slide = (
        Curve(t=(0, 0), x=0)
        .to(t=(1, 0), x=12, ease_x="in_out_sine")
        .to_slide(w=4)
        .clamp()
    )

    tx.chart.notes.append(slide)
```

## Mental model

A `Curve` is a width-agnostic path. It stores waypoints with:

| Field    | Meaning                                               |
| -------- | ----------------------------------------------------- |
| `t`      | Tick or `Position` tuple.                             |
| `x`      | Lane position.                                        |
| `h`      | Air height.                                           |
| `ease_x` | Easing used for lane movement into this waypoint.     |
| `ease_h` | Easing used for height movement into this waypoint.   |

Add legs with `.to(...)`. Each target time must be later than the current end of the curve.

```python
from margrete_rpc.chart.util import Curve

path = (
    Curve(t=(0, 0), x=2, h=60)
    .to(t=(0, 2), x=12, h=120, ease_x="out_cubic", ease_h="in_sine")
    .to(t=(1, 0), x=4, h=80, ease_x="in_cubic", ease_h="out_sine")
)
```

Positions are resolved the same way as note constructors. Inside `with m.open_edit()` blocks, tuple positions
use the chart's time signatures.

## Materialize notes

Use `to_slide()` for ground slides. The `w` value is applied to every generated joint.

```python
from margrete_rpc.chart.util import Curve

slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(0, 2), x=8, ease_x="out_quad")
    .to(t=(1, 0), x=4, ease_x="in_quad")
    .to_slide(w=4)
)
```

Use `to_air_slide()` when the generated path should live in the air lane. Pass `h=` on the curve start and on
legs where height should change.

```python
from margrete_rpc.chart.notes import Tap
from margrete_rpc.chart.util import Curve

air_slide = (
    Curve(t=(0, 0), x=4, h=60)
    .to(t=(0, 2), x=10, h=120, ease_x="in_out_sine", ease_h="out_quad")
    .to(t=(1, 0), x=6, h=80, ease_x="in_out_sine", ease_h="in_quad")
    .to_air_slide(w=4)
)

parent = Tap(t=air_slide.t, x=air_slide.x, w=air_slide.w).add_air(air_slide)
```

Use `to_air_crush()` for air-crush traces. `gap` accepts either raw ticks or a division tuple such as `(1, 16)`.

```python
from margrete_rpc.chart.util import Curve

crush = (
    Curve(t=(0, 0), x=2, h=80)
    .to(t=(1, 0), x=14, h=120, ease_x="out_expo", ease_h="in_out_sine")
    .to_air_crush(w=2, gap=(1, 16), color="blue")
)
```

`Curve` samples eased legs into integer waypoints. Linear legs stay compact, while curved legs get enough
control points to reproduce the sketched motion after conversion to notes.

## Easings

`ease_x` and `ease_h` accept a built-in easing name, an `Easing` object, or a custom callable from `0..1` to
`0..1`.

Built-in names include:

| Family | Names                                  |
| ------ | -------------------------------------- |
| Linear | `linear`                               |
| Sine   | `in_sine`, `out_sine`, `in_out_sine`   |
| Power  | `in_quad`, `out_cubic`, `in_out_quint` |
| Expo   | `in_expo`, `out_expo`, `in_out_expo`   |
| Circ   | `in_circ`, `out_circ`, `in_out_circ`   |

Use a custom callable for shapes that are not in the registry:

```python
import math

from margrete_rpc.chart.util import Curve


def stepped_4(t: float) -> float:
    return math.floor(t * 4) / 4 if t < 1 else 1.0


slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(1, 0), x=12, ease_x=stepped_4)
    .to_slide(w=4)
)
```

Custom easings should return `0` at input `0` and `1` at input `1` so the generated path lands exactly on its
waypoints.

## Inspect and compose curves

Call `points()` to preview the quantized path before creating a note.

```python
path = Curve(t=(0, 0), x=0).to(t=(1, 0), x=12, ease_x="in_out_sine")

for point in path.points():
    print(point.t, point.x, point.h)
```

Use `at(tick)` to evaluate a curve at a specific tick. This is useful for building derived paths that follow
or cross another path.

```python
path = Curve(t=0, x=0, h=80).to(t=960, x=12, h=120)
mid = path.at(480)

print(mid.x, mid.h)
```

Use `then()` or `+` to join curves. If the second curve starts at the first curve's end tick, the shared point
is de-duplicated.

```python
from margrete_rpc.chart.util import Curve

out = Curve(t=(0, 0), x=0).to(t=(0, 2), x=12, ease_x="out_cubic")
back = Curve(t=(0, 2), x=12).to(t=(1, 0), x=4, ease_x="in_cubic")

slide = (out + back).to_slide(w=4)
```

Use `Curve.from_note()` when you want to load an existing long note as a curve, compose it, then materialize
again.

```python
from margrete_rpc.chart.util import Curve

path = Curve.from_note(existing_slide)
copy = path.to_slide(w=existing_slide.w)
```

`from_note()` copies timing, lane, and height path data. Width is intentionally dropped because `Curve` is
width-agnostic.

## Pattern helpers

The helpers `crease()`, `envelope()`, and `rain()` generate common slide-like shapes. They return either a
`Curve` that you can materialize, or notes directly.

### Crease

`crease(base, count=..., x_range=..., h_range=...)` creates a zigzag around a base curve. The first and last
points stay on the base; interior points alternate positive and negative offsets.

```python
from margrete_rpc.chart.util import Curve, crease

base = Curve(t=(0, 0), x=2, h=70).to(t=(1, 0), x=12, h=120, ease_x="out_quad")

slide = crease(base, count=6, x_range=2).to_slide(w=4).clamp()
air = crease(base, count=6, x_range=0, h_range=20).to_air_slide(w=4)
```

Use `.clamp()` after materializing if the offsets may push the note outside the lane field.

### Envelope

`envelope(inner, outer, count=...)` weaves between two boundary curves. Both curves must share the same start
and end time. An even `count` ends back on `inner`; an odd `count` ends on `outer`.

```python
from margrete_rpc.chart.util import Curve, envelope

inner = Curve(t=(0, 0), x=2).to(t=(1, 0), x=6, ease_x="in_sine")
outer = Curve(t=(0, 0), x=10).to(t=(1, 0), x=14, ease_x="out_sine")

slide = envelope(inner, outer, count=4).to_slide(w=2)
```

### Rain

`rain(...)` generates a list of short `AirCrush` notes across a time range. Use `seed=` when you want the same
scatter every time the script runs.

```python
from margrete_rpc.chart.util import rain

drops = rain(
    t0=(0, 0),
    t1=(4, 0),
    step=(1, 16),
    length=(1, 16),
    x_range=(0, 15),
    h_range=(60, 140),
    w=1,
    color="sky",
    seed=42,
)

tx.chart.notes.extend(drops)
```

`x_range` and `h_range` are inclusive. Drops that would extend past `t1` are truncated to end at `t1`.

## Editing workflow

Generated notes are normal note objects. After materializing, you can transform, validate, append, or attach
them just like manually built notes.

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.notes import Tap
from margrete_rpc.chart.util import Curve, crease

m = Margrete()

with m.open_edit() as tx:
    base = Curve(t=(8, 0), x=2, h=60).to(t=(9, 0), x=12, h=120)
    air_slide = crease(base, count=5, x_range=2, h_range=20).to_air_slide(w=3)

    parent = Tap(t=air_slide.t, x=air_slide.x, w=air_slide.w).add_air(air_slide)
    parent.validate()

    tx.chart.notes.append(parent)
```
