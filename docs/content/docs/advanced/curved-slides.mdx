---
title: Curved Slides
description: Sketch curved slides, air slides, and air-crush paths.
---

The [`Curve`](/docs/reference/chart/util/curve/Curve) utility helps you sketch width-agnostic slide paths before
turning them into notes. The usual workflow is to draw a path as a curve, then materialize it as a
[`Slide`](/docs/reference/chart/notes/long/Slide), [`AirSlide`](/docs/reference/chart/notes/air/AirSlide), or
[`AirCrush`](/docs/reference/chart/notes/long/AirCrush). For hand-built notes and joints, start with
[Notes](/docs/basic/notes#long-notes).

```python
from margrete_rpc import Margrete
from margrete_rpc.chart.util import Curve

m = Margrete()

with m.open_edit() as tx:
    slide = (
        Curve(t=(0, 0), x=0)
        .to(t=(1, 0), x=12, ease_x="in_out_sine")
        .to_slide(w=4)
        .clamp()
    )

    tx.chart.notes.append(slide)
```

## Mental model

A [`Curve`](/docs/reference/chart/util/curve/Curve) stores [`Waypoint`](/docs/reference/chart/util/curve/Waypoint) values with:

| Field    | Meaning                                             |
| -------- | --------------------------------------------------- |
| `t`      | Tick or `Position` tuple.                           |
| `x`      | Lane position.                                      |
| `h`      | Air height.                                         |
| `ease_x` | Easing used for lane movement into this waypoint.   |
| `ease_h` | Easing used for height movement into this waypoint. |

The first waypoint anchors the curve, so its easing values do not affect the path. `h` is preserved when you
materialize a ground slide, but it only has visible effect on air-slide and air-crush paths.

Add legs with [`to(...)`](/docs/reference/chart/util/curve/Curve#functions). Each target time must be later than
the current end of the curve.

```python
from margrete_rpc.chart.util import Curve

path = (
    Curve(t=(0, 0), x=2, h=60)
    .to(t=(0, 2), x=12, h=120, ease_x="out_cubic", ease_h="in_sine")
    .to(t=(1, 0), x=4, h=80, ease_x="in_cubic", ease_h="out_sine")
)
```

Positions are resolved the same way as note constructors. Inside `with m.open_edit()` blocks, tuple positions
use the chart's time signatures. See [Time & Position](/docs/basic/time-position) for the full timing model.

## Materialize notes

Use [`to_slide()`](/docs/reference/chart/util/curve/Curve#functions) for ground slides. The `w` value is applied
to every generated joint.

```python
from margrete_rpc.chart.util import Curve

slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(0, 2), x=8, ease_x="out_quad")
    .to(t=(1, 0), x=4, ease_x="in_quad")
    .to_slide(w=4)
)
```

Use [`to_air_slide()`](/docs/reference/chart/util/curve/Curve#functions) when the generated path should live in
the air lane. Pass `h=` on the curve start and on legs where height should change.

```python
from margrete_rpc.chart.notes import Tap
from margrete_rpc.chart.util import Curve

air_slide = (
    Curve(t=(0, 0), x=4, h=60)
    .to(t=(0, 2), x=10, h=120, ease_x="in_out_sine", ease_h="out_quad")
    .to(t=(1, 0), x=6, h=80, ease_x="in_out_sine", ease_h="in_quad")
    .to_air_slide(w=4)
)

parent = Tap(t=air_slide.t, x=air_slide.x, w=air_slide.w).add_air(air_slide)
```

Use [`to_air_crush()`](/docs/reference/chart/util/curve/Curve#functions) for air-crush traces. `gap` accepts
either raw ticks or a division tuple such as `(1, 16)`.

```python
from margrete_rpc.chart.util import Curve

crush = (
    Curve(t=(0, 0), x=2, h=80)
    .to(t=(1, 0), x=14, h=120, ease_x="out_expo", ease_h="in_out_sine")
    .to_air_crush(w=2, gap=(1, 16), color="blue")
)
```

`Curve` samples eased legs into integer waypoints. Linear legs stay compact, while curved legs get enough
control points to reproduce the sketched motion after conversion to notes.

## Easings

`ease_x` and `ease_h` accept a built-in easing name, an [`Easing`](/docs/reference/chart/util/easing/Easing)
object, or a custom callable from `0..1` to `0..1`.

Built-in names include:

| Family | Names                                  |
| ------ | -------------------------------------- |
| Linear | `linear`                               |
| Sine   | `in_sine`, `out_sine`, `in_out_sine`   |
| Power  | `in_quad`, `out_cubic`, `in_out_quint` |
| Expo   | `in_expo`, `out_expo`, `in_out_expo`   |
| Circ   | `in_circ`, `out_circ`, `in_out_circ`   |

Use a custom callable for shapes that are not in the registry:

```python
import math

from margrete_rpc.chart.util import Curve


def stepped_4(t: float) -> float:
    return math.floor(t * 4) / 4 if t < 1 else 1.0


slide = (
    Curve(t=(0, 0), x=0)
    .to(t=(1, 0), x=12, ease_x=stepped_4)
    .to_slide(w=4)
)
```

Custom easings should return `0` at input `0` and `1` at input `1` so the generated path lands exactly on its
waypoints.

## Inspect and compose

Call [`points()`](/docs/reference/chart/util/curve/Curve#functions) to preview the quantized path before creating
a note.

```python
path = Curve(t=(0, 0), x=0).to(t=(1, 0), x=12, ease_x="in_out_sine")

for point in path.points():
    print(point.t, point.x, point.h)
```

Use [`at(tick)`](/docs/reference/chart/util/curve/Curve#functions) to evaluate a curve at a specific tick. This
is useful for building derived paths that follow or cross another path.

```python
path = Curve(t=0, x=0, h=80).to(t=960, x=12, h=120)
mid = path.at(480)

print(mid.x, mid.h)
```

Use [`then()`](/docs/reference/chart/util/curve/Curve#functions) or `+` to join curves. If the second curve
starts at the first curve's end tick, the shared point is de-duplicated.

```python
from margrete_rpc.chart.util import Curve

out = Curve(t=(0, 0), x=0).to(t=(0, 2), x=12, ease_x="out_cubic")
back = Curve(t=(0, 2), x=12).to(t=(1, 0), x=4, ease_x="in_cubic")

slide = (out + back).to_slide(w=4)
```

Use [`Curve.from_note()`](/docs/reference/chart/util/curve/Curve#functions) when you want to load an existing
long note as a curve, compose it, then materialize again.

```python
from margrete_rpc.chart.util import Curve

path = Curve.from_note(existing_slide)

for point in path.waypoints[1:]:
    point.ease_x = "out_cubic"

copy = path.to_slide(w=existing_slide.w)
```

`from_note()` creates mutable control waypoints with linear easing by default, so you can edit each waypoint's
`ease_x` or `ease_h` before materializing. Width is intentionally dropped because `Curve` is width-agnostic.
