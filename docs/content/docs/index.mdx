**Margrete RPC** is a Margrete plugin plus a Python client package that lets you script chart editing for [UMIGURI/Margrete](https://umgr.inonote.jp/en/margrete/intro).

It lets you read and rewrite charts programmatically — place notes, edit events, and apply changes inside the editor.

## Requirements

- Python 3.13 or later
- Margrete 1.8.0 or later

## Installation

### 1. Install the plugin

1. Download the latest release from the [GitHub Releases page](https://github.com/Foahh/margrete-rpc/releases).

2. Open `margrete-rpc-vX.X.X.zip` and copy `margrete-rpc.dll` and `margrete-rpc.ini` to your Margrete plugins directory.

## Quick start

1. In Margrete, open **Extensions** → **Margrete RPC** to start the plugin.

   <div className="flex items-center justify-start gap-1">
     <ImageZoom src={ExtensionToMargreteRpcImage} alt="Extension to Margrete RPC" width="300" />
     <div className="flex items-center">👉</div>
     <ImageZoom src={ActivateThePluginImage} alt="Start the plugin" width="400" />
   </div>

   <Callout type="info">You need to start the plugin each time Margrete restarts.</Callout>

2. Create a file called `example.py`:

   ```python
   from margrete_rpc import Margrete
   from margrete_rpc.chart.notes import Tap

   m = Margrete()  # auto-detect the running plugin instance
   status = m.status()
   print(f"Plugin v{status.server_version} (pid {status.pid})")
   print(f"Log: {status.log_path}")

   with m.open_edit() as tx:
       tx.chart.notes.append(Tap(t=0, x=0, w=4))
   # changes are applied when the `with` block exits successfully
   ```

   This connects to Margrete, print the plugin status, opens an edit transaction, and appends a Tap note to the chart.

3. Run the script and check the editor:

   ```bash
   python example.py
   ```

   A new Tap note will appear in the editor.

   ![Margrete editor changes after quick start](assets/after-quick-start-margrete.png)

## Handle multiple Margrete instances

`Margrete()` with no arguments only discovers the single running plugin instance.

When multiple Margrete instances are running, pass `endpoint` or `instance_id`:

```python
from margrete_rpc import Margrete, list_instances

# list all discovered instances
for inst in list_instances():
    print(inst.instance_id, inst.endpoint)

# connect by explicit host:port (left Margrete)
m_left = Margrete(endpoint="127.0.0.1:1328")

# connect by the instance_id (right Margrete)
m_right = Margrete(instance_id="47824-6a30f65d-b7f8afde84506008")
```
